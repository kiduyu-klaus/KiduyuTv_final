Place your Windows icon file (kiduyutv.ico) in this directory.
The icon should be 256x256 pixels in size for best results on Windows 10/11.

To generate an icon from an image:
1. Use an online tool or tool like ImageMagick
2. Convert your image to ICO format
3. Place it here as "kiduyutv.ico"

The build.gradle will automatically pick it up for the installer.
